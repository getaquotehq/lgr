# Fonts

`Test Tiempos Headline Light` is used for every heading on the site
(`--display`). It is a licensed typeface from Klim Type Foundry and is not
redistributable, so the files are not in this repo.

Drop these two files in this folder:

    TestTiemposHeadline-Light.woff2
    TestTiemposHeadline-Light.woff

Until they are present, headings fall back to `ui-serif, Georgia, Times New
Roman, serif` - still a serif, so the intended contrast against the Inter body
text holds up rather than silently reverting to sans.

Note: the "Test" cut is Klim's trial licence, which is for evaluation and
mockups only. A retail or web licence is required before going live.
